# PyThermoDB-Settings v0.8.0 Release

## Overview

v0.8.0 introduces a robust **Component modeling system** with comprehensive support for chemical species representation. This release focuses on accurate charge inference, species classification, and validation of complex chemical formulas.

## ✨ New Features

### 1. **Advanced Component Model**

The new `Component` class provides a powerful abstraction for representing chemical species with automatic property inference:

```python
from pythermodb_settings.models import Component

component = Component(
   name="Water",
   formula="H2O",
   state="l"
)
```

### 2. **Automatic Charge Detection**

- **Intelligent charge inference** from chemical formulas
- Support for explicit charge notation: `{+}`, `{-}`, `{2+}`, `{3-}`, `{*+}`, `{*2-}`, etc.
- Charge validation against provided values
- Handles complex multi-center charge distributions

**Examples:**

- Simple ions: `Fe{3+}`, `Cu{2+}`, `SO4{2-}`
- Radicals: `CH3{*}`, `NO{*}`, `O2{*-}`
- Zwitterions: `NH3{+}-CH2-COO{-}` (Glycine)
- Mixed charge centers: `M{2+}-L{-}-L{-}`, `M{3+}-L{-}`

### 3. **Species Type Classification**

Automatic classification of chemical species into multiple categories:

- **Neutral**: Standard molecules and compounds
- **Cation**: Positively charged ions
- **Anion**: Negatively charged ions
- **Radical**: Species with unpaired electrons
- **Zwitterion**: Molecules with both positive and negative charges (net neutral or charged)

Species types are detected from formula notation and can include multiple classifications:

```python
# Neutral radical
Component(formula="CH3{*}", name="Methyl radical", state="g")
# -> species_type: ["neutral", "radical"]

# Radical cation
Component(formula="CH3{*+}", name="Methyl radical cation", state="g")
# -> species_type: ["cation", "radical"]

# Zwitterion
Component(formula="NH3{+}-CH2-COO{-}", name="Glycine zwitterion", state="s")
# -> species_type: ["zwitterion"]
```

### 4. **Physical State Support**

Complete support for all standard physical states:

- `"l"` - Liquid
- `"g"` - Gas
- `"s"` - Solid
- `"aq"` - Aqueous solution

### 5. **Comprehensive Validation**

- **Charge consistency checking**: Validates that explicit charge matches inferred charge
- **Species type validation**: Ensures chemical formulas align with declared species types
- **Format validation**: Proper handling of charge notation and radical markers

```python
# Raises ValueError: inconsistent charge
Component(
   name="Methyl radical cation",
   formula="CH3{*+}",
   state="g",
   charge=0  # Conflicts with {*+} notation
)
```

## 🔍 API Examples

### Basic Usage

```python
from pythermodb_settings.models import Component

# Create a simple component
water = Component(
   name="Water",
   formula="H2O",
   state="l"
)
print(f"Charge: {water.charge}")  # -> 0
print(f"Species Type: {water.species_type}")  # -> ["neutral"]
```

### Ionic Species

```python
# Cation
iron_iii = Component(
   name="Iron(III)",
   formula="Fe{3+}",
   state="s"
)
print(iron_iii.charge)  # -> 3
print(iron_iii.species_type)  # -> ["cation"]

# Anion
sulfate = Component(
   name="Sulfate",
   formula="SO4{2-}",
   state="aq"
)
print(sulfate.charge)  # -> -2
print(sulfate.species_type)  # -> ["anion"]
```

### Radical Species

```python
# Simple radical
oh_radical = Component(
   name="Hydroxyl radical",
   formula="HO{*}",
   state="g"
)
print(oh_radical.species_type)  # -> ["neutral", "radical"]

# Radical cation
radical_cat = Component(
   name="Benzene radical cation",
   formula="C6H6{*+}",
   state="g"
)
print(radical_cat.charge)  # -> 1
print(radical_cat.species_type)  # -> ["cation", "radical"]
```

### Zwitterions

```python
glycine = Component(
   name="Glycine zwitterion",
   formula="NH3{+}-CH2-COO{-}",
   state="s"
)
print(glycine.charge)  # -> 0
print(glycine.species_type)  # -> ["zwitterion"]
```

## 📦 Component Model Structure

```python
class Component:
   name: str                    # Component name
   formula: str                 # Chemical formula with charge/radical notation
   state: str                   # Physical state: "l", "g", "s", "aq"
   charge: int                  # Electric charge (inferred or provided)
   species_type: List[str]      # Classification: neutral, cation, anion, radical, zwitterion
```

## ⚠️ Breaking Changes

None. This is a new feature release with full backward compatibility.

## 📝 Notes

- All charge notation must be enclosed in curly braces: `{+}`, `{-}`, `{2+}`, etc.
- Radical notation uses `{*}`, with optional charge: `{*+}`, `{*-}`, `{*2+}`, etc.
- Zwitterions are automatically detected from mixed charge notation
- Explicit charge parameter must match inferred charge from formula notation
